# Security Review Skill
> 코드 파일을 보안 관점에서 리뷰할 때 사용

## 실행 조건
보안 관련 코드(인증, 결제, 정산, 암호화, API) 수정 시 자동 적용

## 체크리스트

### 1. 입력 검증
- [ ] 모든 사용자 입력이 검증되는가?
- [ ] SQL 인젝션 방지 (Parameterized Query)?
- [ ] XSS 방지 (Output Encoding)?
- [ ] 파일 업로드 시 확장자/크기 제한?

### 2. 인증/인가
- [ ] 인증 없이 접근 가능한 엔드포인트가 없는가?
- [ ] 권한 체크가 서버 측에서 이루어지는가?
- [ ] 세션/토큰 만료 설정이 적절한가?
- [ ] MFA가 필요한 곳에 적용되었는가?

### 3. 데이터 보호
- [ ] 민감 데이터가 암호화되어 저장되는가?
- [ ] 로그에 민감 정보가 노출되지 않는가?
- [ ] API 응답에 불필요한 정보가 포함되지 않는가?
- [ ] 에러 메시지에 내부 정보가 노출되지 않는가?

### 4. 결제 특화
- [ ] 금액 변조 방지 (3단계 검증)?
- [ ] 카드번호 평문 처리 없음?
- [ ] 거래 ID 중복 방지?
- [ ] 취소/환불 시 이중 처리 방지?

### 5. 로깅
- [ ] 중요 작업에 감사 로그가 기록되는가?
- [ ] 로그에 민감 정보(비밀번호, 카드번호) 미포함?
- [ ] 로그 보관 기간이 5년 이상인가?

## 리뷰 출력 형식
```
## 🔒 Security Review: [파일명]

### ✅ 통과 항목
- (통과한 항목 나열)

### ⚠️ 개선 필요
- **[위험도]** [문제 설명] (라인 XX)
  - 현재: (현재 코드)
  - 개선: (개선 코드)
  - 근거: (PCI DSS/법규 조항)

### 🔴 즉시 수정 필요
- **[치명]** [문제 설명] (라인 XX)
  - (상동)
```
