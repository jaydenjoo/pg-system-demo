# Product Overview

> updated_at: 2026-03-07 (Sync: 완성도 ~70% → ~85%, 주요 완료 항목 추가)

## 제품 정의

한국 금융감독원(FSS) 기준 결제대행(PG) 관리 시스템. 기존 Java/Spring 레거시를 역설계하여 보안 강화된 신규 버전으로 재구축.

## 핵심 역량

1. **결제 처리** — 토스페이먼츠 스타일 PG API (Basic Auth, paymentKey 기반 승인/취소)
2. **3자 포탈** — 관리자(전체), 가맹점(/m/*), 대리점(/a/*) 역할별 격리된 UI
3. **정산 자동화** — 수수료 4단계 계층(PG마진 > 대리점 > 가맹점 > 결제항목별) + 자동 배치
4. **보안/감사** — PCI DSS 4.0.1 매핑 94%, 감사 로그 해시 체인, MFA, 카드 토큰화
5. **규제 준수** — 전자금융거래법 개정안(2026.12.17 시행) 대응 설계

## 대상 사용자

| 페르소나 | 포탈 | 핵심 니즈 |
|----------|------|----------|
| PG 관리자 | /dashboard/* | 전체 거래/정산 모니터링, 가맹점/대리점 관리, 보안 감사 |
| 가맹점 | /m/* | 자사 거래 조회, 정산 확인, Webhook 설정, API 키 관리 |
| 대리점 | /a/* | 산하 가맹점 관리, 수수료 설정, 거래/정산 조회 |
| 외부 개발자 | SDK/API | PgCheckout SDK로 결제창 임베드, REST API 연동 |
