# PG System 전체 테스트 가이드

> 관리자, 가맹점, 대리점 포탈의 모든 기능을 빠짐없이 테스트하기 위한 종합 가이드

## 사전 준비

### 개발 서버 실행

```bash
# 터미널 1: API 서버 (포트 4000)
cd apps/api && npm run dev

# 터미널 2: Web 서버 (포트 3300)
cd apps/web && npm run dev
```

### 테스트 계정 정보

| 역할 | 로그인 ID | 비밀번호 | 비고 |
|------|----------|---------|------|
| 관리자 (ADMIN) | `admin` | `Admin1234!@` | 전체 시스템 접근 |
| 가맹점 (MERCHANT) | `merchant_test` | `Admin1234!@` | 테스트가맹점 소속 |
| 대리점 (AGENT) | `agent_test` | `Admin1234!@` | 테스트대리점 소속 |
