## 1. 전자금융거래법 개정안 (법률 제21205호)

| 항목 | 내용 |
|------|------|
| **공포일** | 2025.12.16 |
| **시행일** | 2026.12.17 (공포 후 1년) |
| **배경** | 2024.7 티메프 미정산 사태 → PG 규제 강화 |

### 주요 변경사항

#### ① 정산자금 외부관리 의무화 (제25조의4 신설)
- PG업자는 정산대상금액을 **신탁/예치/지급보증보험**으로 외부관리 필수
- 경과 조치:
  - 시행 후 1년차: 정산대상금액의 **60% 이상** 외부관리
  - 시행 후 2년차: 정산대상금액의 **80% 이상** 외부관리
  - 이후: **100%** 외부관리
- 정산대상금액의 양도/담보 제공 금지, 제3자 상계/압류 금지
- **위반 시: 10년 이하 징역 또는 1억원 이하 벌금**

#### ② 자본금 요건 강화 (제30조제3항)
- 분기별 결제대행규모 300억원 초과 시 → **자본금 20억원** (기존 10억원)
- 기존 업자: 시행 후 1년 이내 요건 충족 필요

#### ③ 대주주 변경등록 (제33조의3 신설)
- 대주주 변경 시 **15일 이내** 금융위 변경허가/등록
- 미등록 시 허가/등록 취소 가능

#### ④ PG업 정의 명확화 (제2조제19호)
- 통신판매중개 등 부수적 정산 대행 → PG 범위에서 **제외**
- e커머스, 백화점, 프랜차이즈 내부정산 → 등록 면제 가능

#### ⑤ 행위규칙 신설
- 정산기한 준수 의무 명문화
- 경영지도기준 미준수 시 시정조치 → 불이행 시 영업정지

### 후속 가이드라인
- 「전자금융업자의 결제 리스크 관리 가이드라인」(2026.1.5 ~ 2027.1.14 시행)
- 「PG업자 정산자금 외부관리 가이드라인」(2026.1 시행)
- n차 PG 구조 규제 강화 (하위 PG 관리 의무)

## 2. PCI DSS 4.0.1 (2025.3.31 전면 시행)

### 핵심 변경사항 (코딩 직접 영향)

| 요건 번호 | 내용 | 코딩 영향 |
|-----------|------|----------|
| **3.5.1.2** | 풀디스크 암호화 단독 사용 금지 | 컬럼별 AES-256 암호화 구현 필요 |
| **5.4.1** | 피싱 방지 교육 필수 | 관리자 교육 모듈 고려 |
| **6.3.2** | 소프트웨어 BOM(Bill of Materials) | 모든 의존성 목록 관리 |
| **6.4.3** | 결제 페이지 JS 인벤토리 + 무결성 검증 | CSP 헤더, SRI 해시 구현 |
| **8.3.6** | 비밀번호 최소 12자 (숫자+영문) | 비밀번호 정책 업데이트 |
| **8.4.2** | CDE 접근 모든 계정에 MFA 필수 | TOTP 기반 MFA 전면 구현 |
| **8.6.3** | 서비스 프로바이더: 클라이언트 비밀번호 강화 | 동적 분석 또는 강제 정책 |
| **11.6.1** | 결제 페이지 변경 실시간 탐지 (최소 주 1회) | 변경감지 자동화 구현 |
| **12.3.1** | 대상 리스크 분석(TRA) | 통제 빈도 결정 시 리스크 기반 |

### 12대 핵심 요건 (구조)
1. 네트워크 보안 통제 설치/유지
2. 모든 시스템에 보안 설정 적용
3. 저장된 카드 데이터 보호
4. 개방 네트워크에서 강력한 암호화로 전송
5. 악성 소프트웨어로부터 보호
6. 안전한 시스템/소프트웨어 개발/유지
7. 카드 데이터 접근을 비즈니스 필요에 따라 제한
8. 사용자 식별 및 시스템 접근 인증
9. 카드 데이터에 대한 물리적 접근 제한
10. 네트워크 및 카드 데이터 접근 로깅/모니터링
11. 보안 시스템/프로세스 정기 테스트
12. 정보 보안 정책 유지

## 3. 전자금융감독규정 (주요 조항)

|------|------|----------|

## 4. 개인정보보호법 (관련 조항)

| 항목 | 요구사항 |
|------|---------|
| 수집 동의 | 가맹점 사업자 정보, 대표자 정보 수집 시 동의 |

| 접근 기록 | 개인정보 접근 기록 최소 1년 보관 |

## 5. 코딩 시 법규 체크리스트

### 매 기능 개발 시 확인
- [ ] 민감 데이터 암호화 여부 (AES-256-GCM)
- [ ] 접근 로그 기록 여부 (누가/언제/뭘)
- [ ] 입력값 검증 여부 (인젝션 방지)
- [ ] 에러 메시지 내부정보 노출 여부
- [ ] 인증/인가 적용 여부
- [ ] MFA 적용 여부 (CDE 접근 시)

### 정산 관련 기능 개발 시 추가 확인
- [ ] 정산대상금액 외부관리 연동 여부
- [ ] 정산기한 준수 로직 여부
- [ ] 정산 금액 변조 방지 여부
- [ ] 정산 이력 5년 보관 여부

### 배포 전 확인
- [ ] 보안 스캔 (SAST + DAST) 통과
- [ ] 의존성 취약점 스캔 통과 (npm audit)
- [ ] 비밀 키 코드 내 하드코딩 없음
- [ ] CSP 헤더 설정 완료
- [ ] Rate Limiting 적용 완료
